# Healthcare Patient Data Analyzer

**Portfolio project for a healthcare technology job-tracker assignment (Cognizant)**

This beginner Python program reads **10 fictional healthcare visit records** from a CSV file, converts number fields into usable data, and summarizes the data. It displays the total patient count, average age, total and average visit costs, and visits per department.

## How to run

1. Install Python 3.
2. Keep `patient_analyzer.py` and `sample_patients.csv` in the same folder.
3. Run `python patient_analyzer.py` in a terminal.

No extra libraries or paid services are needed.

## Skills demonstrated

- Python programming and functions
- Reading structured CSV data
- Data types and basic data validation
- Calculations and summary reporting
- Problem-solving in a healthcare context

## Privacy note

All patient IDs and data are **fabricated for education**. No real patient or confidential health information is included.

## Suggested reflection

This project shows how a small Python script can turn records into a clear report. Future improvements could include a database, automated charts, and more robust error handling.
